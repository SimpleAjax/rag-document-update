# Standard return window

Customers can request a return within **21 calendar days** after delivery. The delivery date is day one. The request must reach Northstar Devices before the end of day 21. This replaces the 14-day window in version 2.

# Request details

The customer must use the returns page or contact the support team. The customer must provide the order number and the device serial number. Support must confirm that both values match the order record before it sends a return label.

# Device condition

The device must include its standard accessories and cables. The customer can return an opened device. The device must not have damage that occurred after delivery. The inspection team records missing parts or new damage when it receives the device.

# Damaged or incorrect delivery

The customer must report a damaged or incorrect delivery within seven calendar days after delivery. This report does not reduce the 21-day return period. Support must record the reported issue with the order number and clear photographs when available.

# Return shipment

Use the return label supplied by support only for the approved order. Before packing, match the order number on the approval with the order number on the parcel. Place the device, its standard accessories, and its cables in the parcel, and keep unrelated items out of the shipment. Protect the device with suitable packing material so that it cannot move freely when the parcel is handled. Close and seal the parcel, then place the return label on a flat outer surface where the carrier can scan it. Remove or cover any old shipping labels so they do not direct the parcel to another address. Keep the parcel receipt and tracking details after the carrier accepts the shipment. Northstar Devices records the tracking number at carrier acceptance, so creating a label by itself does not show that the parcel is in transit. If the label is damaged before handoff, contact support for help before sending the parcel. Use the same approved label for the complete return shipment, and do not split the device and its accessories across separate parcels. Keep a copy of the approval with the order details until the returns center confirms delivery. These steps help the receiving team match the package to the approved request and inspect the device with its accessories.

# Refund review

The inspection team checks the device and included parts after delivery to the returns center. If the return meets this policy, Northstar Devices starts the refund within five business days after inspection. The bank can take more time to show the funds.

# Excluded items

Personalized devices and items marked final sale cannot use the standard return window. Applicable law can provide additional rights. This policy does not remove those rights.

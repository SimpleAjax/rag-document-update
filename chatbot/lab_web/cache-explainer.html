HOW TO READ THIS

Cache and compaction answer different questions.

Prompt caching reuses an identical eligible prefix when the provider reports it. Compaction is an application choice that sends a checkpoint with recent context and may refetch evidence later. Neither mechanism proves better answers or guaranteed savings. The initial fixture uses a synthetic returns policy; sample count is zero until reviewed API run data is loaded.
